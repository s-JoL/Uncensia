# 扩展能力

设置管理连接、模型、MCP、工具权限、技能与提示词。记忆和文件在资料库管理，设置提供入口。能力通过已有通用工具按需组合，不为每种创作需求另建执行引擎。

## 模型与参数

`providers` 保存服务地址和鉴权方式，密钥加密存储，API 只返回是否配置。`models` 保存精确模型 ID、协议、输入能力、上下文、输出预算和可选参数。对话走 Pi ModelRuntime，图片与视频走生成适配器。

模型发现读取提供方 `/models`，可探测不同类型列表；只有列表确实不同才采纳其类型。能力建议的优先级是：提供方明确返回值 → Pi 原厂型号目录的精确匹配 → 标注待核实的默认值。已知日期别名显式映射，未知版本不按模型族猜上下文。建议只填表单，保存后不在运行时静默改写。

模型编辑器显示参考来源，可一键采用。上下文窗口决定何时压缩；单次输出预算可低于公布上限，可能包含思考 tokens。采用参考能力不改变思考等级。网关可能另有限制，目录数字不等于已通过相同规模的真实请求测试。

批量添加先验证整组选项再写入；无效数值不留下部分模型。首次初始化与包更新不覆盖用户保存的模型设置。生成操作和参数来源见 [03-generation.md](03-generation.md)。

Gemini 原生协议的请求参数由 `models/params.ts` 处理；用户保存的协议决定实际请求路径，不按名称强行切换。服务端是否接受参数与内容取决于接入的服务，不能从一次成功请求推断所有网关行为。

## 技能

`data/skills/<name>/SKILL.md` 保存本地技能，包内初始内容来自仓库 `skills/`。Pi 发现 agent 与当前工作目录的技能，Uncensia 对同一目录应用启停偏好和运行时上下文。

设置 → 技能支持搜索、查看、添加、编辑、启停和发现诊断。外部技能正文只读，可在原位置修改。编辑提交内容哈希，旧版本冲突返回 409；停用写入 `data/skill-preferences.json`，下一次运行通过 SDK `skillsOverride` 生效，不删除文件或历史正文。

只将摘要列入模型目录，正文按需读取。`disable-model-invocation` 声明的技能仅显式调用；已有 `/skill:name` 仍走 SDK 展开。技能可携带支持文件；当前 Web 添加入口编辑标准 SKILL.md，不是完整的插件安装、依赖管理或热重载中心。

`contexts` 是 Uncensia 提供的可选状态声明：`roleplay` 与 `visual-continuity`。头部解析复用 Pi，代码只按声明附加已保存数据。社区经验见 [community-skills.md](community-skills.md)，上下文生命周期见 [Agent](02-agent.md)。

## 文件、检索与记忆

`save_knowledge` 在资料库启用时提供给 agent，用于用户授权的研究和知识积累。它接收整理后的正文及来源 URL/文件 ID，通过同一入库路径保存 Markdown、去重并建立索引；不是 URL 下载工具。模型先搜索已有资料，保存后用返回的文件 ID 验证检索。返回持久化的实际索引状态：`indexed` 是关键词索引，`ready` 包含向量；索引关闭或失败必须明确报告，保存成功不等于检索验证通过。周期研究使用已有任务调度，不新增独立循环。

文件上传、工作目录交付共用 `library.ts` 入库。文档按内容哈希去重，图片和视频保留独立资源身份；删除资料不伪造历史引用的替代品。

检索按 extract → chunk → embed / keyword 执行。SQLite 保留正文与源向量，LanceDB 是可重建派生索引；没有 embedding 密钥时仍可关键词检索。`file_search` 和 `/files/search` 都支持精确文件范围，范围过滤在结果选择前执行。

当前消息的文档在预算内直接附上正文，超额部分需按 ID 检索；后续轮次保留引用而不重复内联全文。图片当前轮发送像素，历史通过 `view_image` 重新取得。文档修订重建对应索引，失败保留文件并显示状态。

附件名是展示标签，不是工作目录路径。关闭工作目录读取时，技能所需的 `read` 只开放已发现的技能目录，其工具说明必须反映这个边界。当前附件已内联而资料检索列表为空时，不提示模型“没有文件”或要求用户重新上传。

索引只允许当前文件版本的最新任务写回正文、向量和状态；编辑（包括关闭索引后的编辑）会使旧任务失效。可编辑文件的内容 URL 要求缓存重新验证，避免保存后仍读取旧内容。

资料目录、当前附件和检索结果正文都向模型提供精确文件 ID。同名文件仍有独立 ID；引用锚点和文件名不能代替 ID。检索返回片段，不能据此声称读完完整章节。联网搜索可按任务继续查证，提供方拒绝国家条件时明确失败，不自行撤销范围再查。

记忆是明确保存的 key/value 事实，带来源对话。系统按预算读取现有条目；用户可查看、纠正、删除，agent 的写入工具遵循用户明确保存/忘记的请求。角色经历不因出现在故事中就自动成为个人记忆。

记忆修改后在下一次模型调用前刷新，包括同一长任务中的后续调用；已发送的模型请求不受追溯影响。记忆页面在可见时每 5 秒刷新，并在回到页面时刷新，未保存草稿保留。记忆工具执行时重新检查写权限与大小预算。

HTTP 和 agent 写入共用数据库中的原子预算检查，以保存时的全局总量为准；不同对话的同时写入不能各自占用整份预算。交错写入与文件版本回归见 `scripts/audit-concurrent-state.ts`。

## 搜索、工作目录与 MCP

联网搜索使用 `web_search`：Tavily 需要密钥，SearXNG 使用自托管地址；Tavily 可读取页面正文，SearXNG 返回搜索摘要。不存在的提供方明确报错。

| 工作目录权限 | 可用工具 |
|---|---|
| read | Pi read、grep、find、ls；启用资料库时可 publish_file 交付文件 |
| write | Pi write、edit，移动、删除、恢复；启用资料库时可 import_file 导入资料 |
| shell | Pi bash |

工作目录由 `capabilities.coding.workspace` 指定。同一文件写入串行，覆盖/删除备份到 `data/coding-trash`，需要审批的操作见 [Agent](02-agent.md)。设置中的“工作目录访问”分别控制查看文件、修改文件和运行命令。命令按服务进程权限执行，工作目录与文件开关不是 shell 的隔离边界。

MCP 使用 stdio 或 Streamable HTTP。设置管理进程/地址、参数、环境变量、请求头、启用状态和重连；不自动回退到旧 HTTP+SSE。工具来自已启用、已连接的服务器。

## 提示词与定时任务

“技能与长期指令”使用独立的 `learning.skills`、`learning.prompts` 开关，分别提供 `manage_skill`、`manage_prompt`。任一项开启时提供 `learning_history`，仅返回对应类别；每次调用重新检查权限。旧配置首次保存时继承原有 coding.write 的授权状态并独立持久化，以后修改文件写入权限不再联动。已有技能的发现和读取不依赖修改开关。技能启停和提示词更改下一轮加载。`data/learning-history` 在修改前保留原因、来源对话与新旧正文，设置 → 技能展示最近 50 次尝试；备份记录不代表写入一定成功。恢复时使用旧正文与当前版本再次更新。源代码仍走工作目录工具、备份和审批，验证与部署状态分别报告。专用工具开关不是文件系统隔离；开放 shell 或相应目录写入时，本机工具仍可修改技能与指令文件。

## 工具与权限整理（2026-09-11）

Pi 默认只提供 read、write、edit、bash，grep/find/ls 是可选读取工具。Uncensia 的增量工具服务于持久资料、媒体任务及应用状态，不应全部归为 Pi 内置工具。

- 删除“允许助手改自己”的一键读写按钮及常用设置的重复入口：它不是训练模型或自动升级程序，原名称无法准确表达权限。
- 拆开原来由 coding.write 同时决定的文件写入、技能修改和长期指令修改；界面按作用对象分组并说明生效时间。
- grep/find/ls 与 shell 有功能重叠，但在不允许命令执行时仍有独立作用，暂保留。移动、删除、恢复工具带备份和审批契约，不能直接用裸 shell 替代。
- file_search 是相关片段检索，read_resource 是原文范围读取，quote_resource 是稳定展示；三者不合并。import_file/publish_file 连接资料库与工作目录，acquire_resource 下载原件，save_knowledge 保存整理后的研究，语义不同。
- 每个额外媒体模型增加工具，以及低频管理能力常驻，仍是后续工具数量收敛点。本次不新增工具加载器、不删除现有生成入口，不将权限页重设计冒充已完成所有工具精简。

验收：audit-learning 覆盖旧配置两种迁移、权限独立、已取得工具撤权、版本冲突与真实 Runtime 调用；Web 隔离实例操作关闭技能与文件修改，长期指令保持开启，刷新持久保存。完整 audit、类型检查和构建通过（日志 `run/permissions-audit.log`）。桌面与 390px Web 页面已实看，窄屏无横向溢出。

全局和工具提示词在设置管理，并落到 `data/prompts/global.md`、`tools.md`；文件存在时以文件为准。模型可配置专属系统提示词。保留原有 writing brief 和用户自定义内容，更新使用包资源所有权机制。更改通常下一轮生效，源代码变更需重启。

任务入口在侧栏、聊天页顶部，设置页保留同一管理组件。支持一次执行、持续推进、固定间隔重复，能指定开始时间、轮数上限，查看助手报告进度、真实执行记录、下一次时间和失败原因。可以新建对话或选择已有对话，模型也能通过 `create_task` 按自然语言请求安排。

暂停允许当前轮结束后停下，取消请求停止当前轮并阻止后续执行；继续不删除已有结果。服务必须运行，关网页不影响执行，关机期间不会唤醒电脑。当前不提供系统推送、日历规则或费用预算，具体续跑与恢复契约见 [Agent](02-agent.md)。
