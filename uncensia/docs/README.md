# 文档

[English](README.en.md) · [项目首页](../../README.zh-CN.md)

Uncensia 是自托管、单用户的个人 AI 创作与陪伴工作室：对话、智能体、文件、记忆与图像／视频生成在同一空间协作，全部自备密钥，不设应用层内容限制。Web 与原生 iOS 共用同一服务与数据。
