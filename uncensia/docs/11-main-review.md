# main 对比审阅与模型能力边界

日期：2026-09-07。已实际 `git fetch origin main`；本地 main、origin/main、当前 HEAD 均为 `66f67a6a0e1fd1a5236dfe9aea4c5250ca5c6223`。对比对象是 main 与当前**整个未提交工作区，包括新文件**，不是 HEAD 间的空 diff。不把已有重构全部归为本次修改。

结论：新版在通用任务、轻量技能创作、资料交付、多轮控制和执行可见性上更强，成熟组件复用更充分；自有服务端代码略少，Web 与依赖规模增加。它不是对 main 所有旧兼容行为的严格超集，也没有证据证明同一模型在所有内容任务上都胜过 main。

## 复用与简洁

主要复用增量是 Pi `AgentSession`/`SessionManager`、原生工具与生命周期，代替本地 compaction 与旧 SQLite session adapter；parse5 代替对巨大 HTML 原文索引；LanceDB 代替自写向量评分循环。React、Radix、MCP SDK、Pi core 和原生媒体 job 原本已存在，不能重复记为新增成果。会话全文搜索复用 [SQLite FTS5 trigram](https://www.sqlite.org/fts5.html#the_trigram_tokenizer)，只索引当前可见正文，避免为查询打开所有 JSONL 会话树。

统计按版本内文本文件的物理行数，含注释/空行，不把行数等同于质量。排除 runtime、data、run、ComfyUI、无关 hermes-webui 和独立 mobile 目录；新增未跟踪的 Uncensia 文件计入。脚本、文档、技能与客户端分开计，不以删除测试来制造精简。

可确认的是自有生命周期和工具逻辑更集中。不能确认“整个仓库更短”“所有模块都更少”或“已证明更快”：Web、iOS、技能和验证代码均增长，尚无同环境全面 main 性能基准。现有真实创作的前后回放基线也不全是干净 main，不能声称做过严格 main/新版模型质量 A/B。

## 本次审阅发现与修复

1. **搜索退化**：逐会话开树/缓存及工具元数据干扰命中，改为 SQLite 当前正文索引；覆盖4200条工具/推理元数据干扰、短中文、引号换行、分支重复 ID、重投影/删除/更新和索引重建。浏览器搜索并跳到准确消息通过。
2. **默认文件复活**：已安装后被用户删除的 skill/workflow，重启不再重新安装；继续保留用户编辑，仍能更新未修改包文件及安装新增文件。实际 services 重启检查通过。
3. **200项分页截断**：引用选择器改成真实分页，资料页刷新也按接口页大小取完整已加载窗口。241份隔离资料实际加载、末页引用、编辑保存后仍显示241项；手机搜索精确选中同一文件。
4. **选择模型失败不可见**：服务端保存成功才更新会话选择，失败显示错误，不再吞掉异常。类型/构建检查通过，未把它说成单独的真实提供方失败回放。
5. **参考状态静默改写**：复用 Zod，拒绝非法角色、超限文本/引用、重复引用及不存在的用户提交图片；验证在任何对话写入前完成。历史 fork 保留被删除参考的原 ID。HTTP 用例验证错误400、其他字段不变与分支不丢身份。
6. **iOS 抹掉 Web 对白示例**：补齐 Codable 字段与缺省解码，并增加跨客户端 PATCH 保留测试。代码已修，Windows 没有执行原生 XCTest/Swift Testing；不能计作原生通过。
7. **直接打开旧 main 数据**：新 Db 在 DDL 前识别旧会话结构并拒绝启动。回归验证错误清楚且旧数据库字节不变；没有偷偷新建空历史冒充升级完成。

## 升级与兼容收敛

- 主流程保留 stdio 与 Streamable HTTP MCP；旧 HTTP+SSE 自动回退已删除。只提供 SSE 的旧服务需改用支持的端点，不能宣称全部 MCP 服务兼容。
- LibreChat 精简请求开关、旧 seed/schema/session 自动迁移及 boogu-edit-turbo 包工作流已删除。这些是工作区原有精简取舍，不是模型能力限制，也不在此次恢复。
- **未转换的 main 数据不能直接升级运行，也没有随仓库交付的通用升级工具。** 先停服务并完整备份数据库、会话树、密钥文件、素材和自定义资源；在副本离线转换 schema 与旧 SQLite 会话为 Pi JSONL，再逐项核对条目内容、分支/leaf、资源 ID、消息投影和 prompts，隔离启动通过后才切换。不要只补两列以跳过启动检查，也不要把旧数据目录当新安装目录。
- 这台机器此前已做一次有备份的离线转换：11会话、534树条目、513投影消息，核对记录见 [10-refactor-validation.md](10-refactor-validation.md)。这是本机已完成状态，不是普遍的升级能力；对外发布前仍需单独交付可复现的升级流程。
- “通用升级流程”只指其他旧安装重复迁移数据的方法，不是另建自动更新系统。当前用户这台机器已迁移，它不构成本轮产品目标未达成的理由；本轮只保留旧数据误启动的明确保护。
- 依赖已有变化，部署前必须安装当前 lockfile，不能沿用旧 node_modules。此次未提交、推送或重启正式服务。
