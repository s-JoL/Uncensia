# 资料与连续工作验收计划

2026-09-11。范围为后端和 Web，不改 iOS。保留现有模型选择、writer prompt、Pi 循环、MCP、资料库和创作台。

## 最终行为

1. Agent 和用户可从 HTTP(S) 链接获取文档或图片；保留原件、来源、内容校验和索引状态，图片产生真实 img ID，可查看并用于后续编辑。
2. Agent 可以列出资料、按范围读取长文，直接展示文件、历史消息或工具结果的一段原文，无需重抄。展示内容保存快照，源文件修改不会改变旧引用。原文可下载和复用。
3. WebUI 可从链接导入、查看原件和来源、展开引用；跨轮引用不会串文件，视觉模型能力可见，图片不因容器尺寸变形。
4. 对连续任务提供可持久保存的明确交付项与状态，依靠已有任务调度和生成记录恢复，不把模型声称完成当作资产证据。
5. 历史、资料与反馈能被 agent 检索；用户能留下对应具体回复的反馈。保存实际执行上下文，便于归因。
6. 外部服务继续使用 MCP，展示连接与错误；网页资料获取不依赖 shell 权限。已连接能力通过真实流程验收；未提供浏览器或邮件凭据不能算实际接入完成。

模型与协议测试使用隔离数据目录、本地测试服务器和普通文本/图片，不修改生产历史；部署后仅新增一份公开 RFC 文档验证正式导入。模型和生成实测单独记录实际请求与结果；测试桩通过不冒充模型效果通过。正式部署、提交与推送分别记录。

## 实现与验收记录

2026-09-11 完成实现与验收，包括正式原件导入复测。

- 原件获取：新增 `acquire_resource` 与 Web 链接导入，记录原始/最终 URL、SHA-256、服务器声明的编码和索引结果。限制下载大小、重定向、取消与公共地址；默认使用系统 DNS，可显式配置下载专用 DNS-over-HTTPS。
- 阅读和复用：新增 `list_resources`、`read_resource`、`quote_resource`，支持文件、当前会话消息/工具结果，以及 `excerpt://` 链接中的摘录编号。按行或完整段落读取；摘录是独立不可编辑快照，Web 直接加载正文，模型只返回引用与少量边界预览。PDF/DOCX 使用提取后的文本，EPUB 按 spine 章节顺序读取；文本编码可显式指定。
- 连续工作：新增 `search_history`、`track_deliverables`，保存回复反馈与实际提供给模型的工具/视觉能力记录。交付项必须关联真实文件或摘录；模型的“已核验”是其提交的证据说明，不是系统对质量的自动背书。
- 引用与图片：新搜索锚点不再逐轮从零计数；旧引用按所属轮次解析。增加原图/成品并排对比与视觉模型提示。修复查看图片时不完整元数据覆盖已知后端、尺寸和父图的问题；旧来源面板可以从实际生成任务恢复这些事实。

真实测试先暴露了错误：模型猜行号时引用了目录或额外段落；新增行号、段落选择和边界预览后，同一小说任务准确引用了正文第一段。跨轮又发现模型混淆摘录编号和消息编号；提供明确 `quote_id` 阅读与交付登记后重测通过。保留了这些失败证据，不将 run 的 completed 当作业务验收通过。

证据保存在本机 `run/resource-validation-20260911/`（`acceptance.json`、各 `live-*.json` 与隔离数据库）、`run/resource-audit-final.log`、`run/resource-e2e.log`、`run/resource-e2e-generation-retest.log`。测试桩只验协议；真实模型的行为与图片结果单独核对。

## 运行限制与部署

- 部署前备份数据，使用项目启动流程更新；本机与公网健康检查通过。
- 代理使用虚拟 DNS 地址的机器需显式配置下载专用 DNS-over-HTTPS；公共地址校验保留。正式 RFC 文档导入已核对原件字节、SHA-256、索引状态、分页正文及来源。
- 当前未配置 MCP 连接；现有 MCP 连接/错误状态与协议回归仍保留。登录网站、邮箱和金融账户没有实际接入，不以通用 MCP 支持冒充已完成账户联调。
- 扫描 PDF 的 OCR、站点登录抓取、模型写作/NSFW 品质和拒绝率，不在这次资源与工作流验收的通过结论内。未改 iOS。

最终 review：原文分页不重复查询来源；等价范围共用摘录快照；引用映射按轮复用；恢复网格文档编辑入口，固定摘录不提供编辑按钮；图片/视频来源页不尝试文本提取；工具上下文在技能工具组装后记录。
