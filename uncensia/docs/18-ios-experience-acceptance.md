# iOS 体验优化与对抗验收

2026-09-12，分支 `codex/ios-experience`。从原 `codex/ios-streaming-parity` 保留已有修复，合入最新 `origin/main` 的 `af56e1e`（资料复用与独立权限），再执行本轮原生优化。

## 目标

以 ChatGPT iOS 的阅读、输入、生成反馈和内容操作为交互目标，以当前 WebUI 为功能依据。目标必须由实际行为验证，不能用编译成功、按钮存在、测试数量或相似外观代替。

| 场景 | 验收要求 |
|---|---|
| 长回复生成 | 首个增量不等合批定时器；后续增量在后台合批，顺序和尾字完整 |
| 生成中输入 | 保留逐字草稿，输入与停止可操作；追问确认期间防重复提交 |
| 上翻阅读 | 真正进入历史段落后，继续输出和结束替换时该段落位移不超过 3 pt |
| 返回最新 | 点击后最后一行确实落在阅读区内；键盘和多行草稿不遮住末行 |
| 更早历史 | 实际请求上一页，并保留可见段落的像素偏移；不能只校验消息 ID |
| 媒体与引用 | 延迟图片和原文引用不推走读者；鉴权下载、预览、返回与分享可用 |
| Markdown | 代码、表格、公式、链接与引用都保留原义；未闭合的流式结构不破坏旧块 |
| 恢复与切换 | 断流、前后台、迟到响应、编辑重试、连续发送不混会话、不重复、不丢历史 |
| WebUI 新资料能力 | 摘录原文、资源分页与编码、来源、交付反馈记录、链接导入和反馈操作可达 |
| 屏幕与性能 | 常规 iPhone、小屏与 iPad 验证；记录系统滚动指标和实际截图，区分模拟器与真机证据 |

## 本轮独立分工

- 流式与状态 agent：事件交付、历史恢复、发送和异步归属；完成后对抗复核渲染和资料接口。
- 渲染 agent：增量 Markdown、公式、鉴权媒体和引用；完成后对抗复核发送与恢复。
- 对抗 QA agent：独立制定失败条件、编写可控 HTTP 场景、实际界面复查，拒绝只验证按钮存在。
- 主代理：合并最新代码、输入与滚动交互、草稿交接、构建运行、失败复现和最终整合。

- `scripts/ios-streaming-fixture.py`：`127.0.0.1:18095`，持续中文/表格/代码流，终态、分页、引用和资料接口可控。
- `StreamingExperienceTests` 以实际可见文本和服务端请求记录断言；带键盘的手势限定在导航栏下方、输入区上方的真实阅读区域。
- `DeviceComparisonTests` 仅在显式开启 `UNCENSIA_DEVICE_COMPARISON=1` 的真机上采集已安装 ChatGPT 和 Uncensia 的界面；不发送消息或改变对话。

## 已验证的行为与修复

- 首个流式增量立即交付；后续最多按 50 ms 或 64 个事件合批。SSE 支持跨包 UTF-8、混合换行分隔和大帧。完成、失败和取消立即恢复控件，慢历史同步不会锁住下一次发送。
- Markdown 只重解析尚未结束的尾块；已完成正文、代码、表格保留稳定身份与缓存。424 个逐字前缀与完整解析结果一致；160 KB 历史后追加 12 字节只扫描新增 12 字节。
- 终态不再把长答案放进额外的水平容器。修复前实际测得消息外壳比正文多出 1,407 pt 空白，点击返回最新会落到空白处；修复后正文与外壳报告相同高度，末行落在导航栏和输入区之间。
- 聊天消息采用准确尺寸的普通栈，保留每页 20 条历史与按需加载；超长流式场景中懒加载栈曾出现 SwiftUI 持续重排和主线程满载。分页恢复根据旧可见段落和安全区换算偏移，用户新手势立即取消旧恢复任务。
- 输入框不再为独立的收键盘工具栏额外占用一行；保留系统交互式收键盘。生成中输入、追问防重、停止、消息全文复制、代码复制、照片/视频和文件附件均有原生入口。
- 草稿、附件和上传计数按服务器与会话归属；资料库传入附件在旧草稿保存后交接。上传完成与草稿恢复相交时，用待合并队列补回已读取快照缺少的附件。
- 公式使用原生字体绘制，并修正 CoreText 坐标转换造成的颠倒。原文引用用固定的紧凑画布和内部滚动，加载前后不改变外部高度；包含来源、行号、复制和鉴权下载。资料阅读支持分页、来源与编码切换，反馈失败保留正文并可重试。

## 真机与对比边界

已确认配对的 iPhone 12 Pro 安装了 ChatGPT 1.2026.244。Uncensia 的应用开发签名可以构建、安装和启动；自动 UI 测试运行器缺少签名描述文件，Xcode 报告没有登录开发者账户。因此，目前证据来自原生模拟器和可控后端，不能表述为已完成 ChatGPT 的同机交互、帧率、功耗或网络条件对比。

`DeviceComparisonTests` 已准备好，需 Xcode 账户与测试签名可用后执行。真正同机运行与用户真实工作负载仍是“可媲美 ChatGPT”的最终验收条件；不以相似外观或通过数量替代。

## 设计依据

[Apple SwiftUI 性能说明](https://developer.apple.com/documentation/xcode/understanding-and-improving-swiftui-performance) 强调减少长时间视图更新和无效更新；[滚动容器说明](https://developer.apple.com/documentation/swiftui/creating-performant-scrollable-stacks) 说明懒加载的性能与尺寸估计取舍。本轮采用稳定消息身份、增量正文块、后台事件合批、带安全区域换算的阅读位置恢复，并以运行证据检查效果。

公式使用固定版本 SwiftMath 1.7.3，授权与字体许可见 `native-ios/Resources/SwiftMath-LICENSE.txt`。公式在本地原生排版，不启动额外网页进程。
