## 贝克街：同一个角色的三个镜头

2026-09-14，通过 Uncensia 生成适配器所用的同一批 Siray Seedream 5.0 Pro Spicy 模型，做了三幅福尔摩斯与华生（公版角色）的水彩电影感插画：一次文生图，随后两次以**第一张**为来源的改图。

| 步骤 | 后端 | 成品 |
|---|---|---|
| 立住书房场景 | Siray · Seedream 5.0 Pro T2I | [221B 贝克街](sherlock-01-study.png) |
| 重拍这一刻 | Siray · Seedream 5.0 Pro I2I（来源：场景 1） | [拿放大镜的福尔摩斯](sherlock-02-clue.png) |
| 带进新场景 | Siray · Seedream 5.0 Pro I2I（来源：场景 1） | [走进雾中](sherlock-03-street.png) |

两次改图都从第一张分叉，而非彼此串联，因此两人始终可辨，而姿态、机位与场景都在变。画风与人物贯穿全序列，细节仍会有出入——视觉连续性是“一致”，不是“逐像素相同”。[提交的提示词、模型 ID、任务 ID 与 SHA-256](sherlock-manifest.json)。

## 一个搭档，以及一次合成

2026-09-14，创建了一个原创虚构角色（不含任何私人数据），让 TA 贯穿不同场景；又把两张独立肖像合成到同一画面——全部通过同一批 Siray Seedream 5.0 Pro Spicy 模型完成。

| 步骤 | 操作 | 成品 |
|---|---|---|
| 设定角色 | 文生图 | [雨天咖啡馆](companion-01-cafe.png) |
| 同一人，换心情 | 改图（来源：咖啡馆） | [霓虹夜街](companion-02-night.png) |
| 同一人，在家中 | 改图（来源：咖啡馆） | [家中夜晚](companion-03-home.png) |
| 第二个角色 | 文生图 | [肖像 B](compose-b-friend.png) |

两种心情都从第一张咖啡馆肖像分叉，保留了她的脸、雀斑与星星项链。最后一张是**一次**改图任务同时喂入**两张**参考图，因此两张脸都被带进新场景——也就是 Uncensia 里“使用固定的图片参考”／追加参考所对应的多图合成。[提交的提示词、模型 ID、任务 ID 与 SHA-256](companion-manifest.json)。

## 仙境茶会：读取、配图、局部修改

2026-09-13，在独立本地实例导入 [《Alice’s Adventures in Wonderland》英文原文](https://www.gutenberg.org/ebooks/11)。助手定位第七章茶会后，通过真实生成队列完成三幕水彩插图：第一张文生图，后两张以第一张为来源编辑。

对话使用 Siray 的 DeepSeek V4 Flash，图片使用 Siray Seedream 5.0 Pro T2I / I2I，尺寸均为 1248 × 832。这个例子记录实际创作流程，不代表所有提示词都能一次完成。

最初的对话提供方返回余额不足，演示明确改用 Siray。随后补充了准确文件 ID，纠正章节定位；首次媒体尝试发现适配器没有声明文生图，补齐后继续执行。失败过程没有被当作成功出图。

第二幕初稿把两个动作画成两只怀表，后续只对这一张提出局部修正，第一和第三幕保留。人物与水彩风格可辨认地延续，但细节并非像素级一致。

怀表修正已完成：终稿中只有一只表，由帽匠举到耳边。[初稿](alice-02-pocket-watch-v1.png)保留用于比较。随后在新对话中复用三张终稿，生成图文改写和明确标注的原创续写；这一步没有再生成图片。

## 如何复现

先在 Uncensia 配好相应模型。首图使用的 ComfyUI 工作流需要 `lustify_v10_krea_turbo_int8_convrot.safetensors`、`qwen3vl_4b_fp8_scaled.safetensors`、`wan_2.1_vae.safetensors` 及工作流声明的节点类型。采用 8 步、CFG 1、Euler、beta 和 shift 4，图片种子为 `9082026`。

1. 在创作台选择生图和 Lustify，复制参数清单第一项的提示词与尺寸。
2. 选择图片编辑和 Seedream，将第一张图作为源图，使用第二项提示词与 `1248x832` 尺寸。
3. 选择 Wan 首尾帧图生视频，以**站台图**为首帧，不是海岸编辑图。使用最后一项提示词、4 秒、720p、16:9，关闭声音和供应商提示词扩写。

清单中的素材 ID 属于这个独立演示安装；复现时请在自己的安装中选对应源图。云端运行可能产生费用。服务商更新和生成随机性意味着相同参数也可能得到不同结果。

这些任务通过 Uncensia 的真实队列和适配器，在独立数据目录中提交。两张图片均已实际看图检查，MP4 的尺寸、时长和代表帧也已检查。编辑保留了可辨认的发型、雨衣、围巾与摄影风格，同时改变姿态和环境。这是一个展示案例，不是保证所有姿态下身份完全一致的基准测试。

GIF 是 MP4 的较小动态预览；原始图片和服务商返回的原始 MP4 单独保留。参数清单只包含公开提示词和参数，没有凭据或服务商下载地址。
