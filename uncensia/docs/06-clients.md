# 客户端

两个前端，同一个 `/v1`。谁也没有私有端点。新能力先在服务端出现。

## Web

Web 登录页与侧栏支持 English / 中文切换；原生 iOS 带有两种语言资源，跟随系统应用语言。文案、日期与动态字段说明通过本地化层显示，用户内容保持原文。维护与验证见 [本地化](16-localization.md)。

`src/web/`。Vite 打到 `dist/`，生产里由 Node 同进程送出；开发时 Vite `:3100`
把 `/v1` 代理过去。

Web 为三个工作区与设置入口；iOS 采用同一工作区划分，原生重建规划见 [15-ios-native.md](15-ios-native.md)：

| 栏 | 路径 | |
|---|---|---|
| 对话 | `/`、`/c/:id` | 转写、流式、附件、编辑/重试、继续、停止、运行中转向/排队追问、审批、角色/场景、视觉连续性、后台工作 |
| 任务 | `/tasks` | 创建一次/持续/定期任务，指定时间与轮数，查看进度、执行记录、暂停/继续/取消；聊天页顶部提供同一组件 |
| 创作台 | `/studio` | schema 表单、job 队列、砌体图库（图+视频）、血缘 |
| 资料库 | `/library`、`/library/memory` | 文件、作品、检索、记忆及来源 |
| 设置 | `/settings/…` | 常用默认模型与资料入口；连接、模型参考能力、MCP、工具权限、技能、定时任务、个性化和登录管理 |

`api.ts`：Bearer + cookie；SSE 失败两次改长轮询；`followRun` / `watchJob`。
提前结束且没有终态的 SSE 也计为失败，重连按游标去重；鉴权失效或资源删除明确报错，超时和临时服务错误仍可重试。只有实际完成的回答触发完成通知，取消与失败不冒充完成。
可见且空闲的聊天页每五秒检查会话版本，自动接上其他客户端发起的 run；版本变化时重新读取转写，包含另一端的分支切换。隐藏页面和正在编辑的设定草稿不会被轮询重置。
对话地址放在 URL 里，避免移动浏览器杀后台后丢掉当前会话。

Web 使用中性明暗主题、阅读宽度约束、居中的新对话输入入口和侧栏导航。模型选择在顶栏，分支与压缩收进“对话操作”；流式期间保留转向与排队追问。未发送草稿按对话保存于当前标签的 sessionStorage，包括文字、附件元数据及图片用途，刷新或切换页面后可恢复。

资料库默认使用作品卡片，支持切换列表；卡片能加入新对话或带“待编辑原图”用途进入聊天。图片查看器复用 Radix Dialog 管理焦点和 Escape，提供修改、作为参考、保存与来源。设置包含常用、连接服务、模型、扩展连接、技能、工具与权限、定时任务、个性化和访问与登录，并支持分组查找。

资料筛选只接收当前条件的最新请求，避免旧响应覆盖新列表。记忆首次加载失败显示保留导航的错误与重试入口。

对话设定将场景笔记与示例对白分开，保存按钮固定在弹窗底部。可选故事资料中可展开
“从角色卡导入设定”：选择或粘贴 Character Card V2 JSON，预览后替换角色、场景和
示例草稿，再保存。人物身份、世界、写作方式与通用设置保持原值。导入前原文件不会
被改写，预览也不会写入对话。当前是文本设定提取，不支持 PNG 卡片、自动开场、
World Info 激活或卡片专属 system 覆盖；有这些字段时会列明未应用内容。

创作台提交走 `POST /jobs` + `watchJob`。表单来自 `/studio/tools` 的 adapter
schema，没有 MCP 旁路。表单只渲染字段的 `title`：schema 里的 `description` 是
写给模型的（包括后端自己的提示词建议），印给人看等于把别人的说明书摆在读者面前。

冷启动拉不到 bootstrap 时给一屏可重试的错误，不是空白；已经有快照时刷新失败只
提示，因为手上那份是旧的而不是没有。

## iOS / SwiftUI 原生重建

`native-ios/` 按最新用户要求从头实现 SwiftUI 客户端，最低目标为 Web 全功能。当前实现、分工和验收边界见 [15-ios-native.md](15-ios-native.md)。共用 `/v1`，不引入客户端专属后端接口。旧 `ios/` 不恢复，Conduit 的流畅性机制通过原生状态与滚动设计借鉴。

原生开发入口为 `bash scripts/native-ios.sh`；共享后端验收夹具为 `scripts/ios-ci-fixture.ts`，只在独立测试目录运行。旧 Flutter 客户端与专用 CI 已移除。
